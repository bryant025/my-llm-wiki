# 原始資料暫存區 (Raw Sources)

此目錄用於放置您收集到的原始資料：
- 烹飪科學書籍章節摘錄 (`.txt`, `.md`, `.pdf`)
- YouTube 料理科普影片的逐字稿
- 網路優質科普文章備份
- 您的零散實驗筆記

---

### 如何使用：
1. 將文件放入此目錄（例如 `sources/raw/kenji-steak-notes.txt`）。
2. 在對話中指示 Agent：「**請幫我消化 `sources/raw/xxx` 並整合進食品科學 Wiki**」。
3. Agent 會依照 `AGENTS.md` 自動將萃取後的內容分類歸檔至 `wiki/` 各子目錄中，並自動更新 `INDEX.md`。
